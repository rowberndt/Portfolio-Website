FEATURED PROJECT • APPLIED ML & DATA SYSTEMS

Foundations

From live market data to reproducible model research.

A Python research system that connects data collection, durable storage, feature engineering, and probabilistic modeling. My focus: keeping the data trustworthy and the evaluation honest.

  • Python
  • PyTorch
  • SQLite
  • Parquet
  • Docker
Inside the project +

The challenge

Live feeds can disconnect, repeat records, and reveal outcomes after a decision. A useful research dataset needs to preserve that timing.

The implementation

  • WebSocket and REST ingestion with persistent record identities, replay, and Parquet exports.
  • A regularized logistic-regression baseline with shared historical and inference feature transforms.
  • Event-based chronological evaluation and separate outcome labels to reduce data leakage.
  • A PyTorch attention architecture for joint order-book modeling, currently under development.

What’s next

Complete training and held-out evaluation of the joint model. The system is a research project; model profitability has not been established.

02 / COMPUTER VISION · LEARNING PROJECT

Teaching a network to see

PyTorch notebooks for handwritten-digit and cat-versus-dog classification, from image preprocessing to training loops and validation.

  • PyTorch
  • OpenCV
  • CUDA
  • Matplotlib
Explore the approach +

The MNIST classifier maps 784 pixels through three 64-unit hidden layers to 10 digit classes, using Adam and negative log-likelihood loss. Its saved notebook reports 97.2% test accuracy in a single run; that is a recorded result, not a new benchmark.

The image-classification notebook preprocesses grayscale images to 50 × 50 pixels and uses three convolutional layers, max pooling, GPU training, and a 10% validation split. Training and validation accuracy and loss are logged for visualization.

03 / ML FUNDAMENTALS · LEARNING PROJECT

Neural networks, from scratch

A NumPy implementation of a neural-network forward pass, making the math behind dense layers, activations, and loss explicit.

  • Python
  • NumPy
  • Linear algebra
Explore the approach +

Using the NNFS spiral dataset, this exercise implements two dense layers, ReLU, numerically stable softmax, and categorical cross-entropy. It accepts integer or one-hot labels.

The implementation covers the forward pass and loss calculation. Backpropagation and optimization are a future extension. The interactive network above uses the same 2 → 3 → 3 structure with illustrative weights.
